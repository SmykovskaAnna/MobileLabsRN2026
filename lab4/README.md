# Лабораторна робота №4
Тема: Робота з файловою системою в React Native з використанням бібліотеки expo-file-system.

Мета: Опанувати механізми роботи з локальною файловою системою мобільного пристрою, використовуючи можливості бібліотеки `expo-file-system`. Закріпити навички реалізації базових операцій над файлами й папками, організації файлової навігації та аналізу стану файлової системи.

## Опис проєкту
Реалізовано мобільний застосунок «Файловий менеджер», який дозволяє переміщуватись між папками локальної файлової системи, створювати, переглядати, редагувати та видаляти файли й папки, переглядати детальну інформацію про об'єкти файлової системи, а також відстежувати статистику використання пам'яті пристрою.

Структура репозиторію:
- `lab4/` — вихідний код застосунку

## Інструкція із запуску
1. Перейдіть у папку проєкту:

```bash
cd lab4
```

2. Встановіть залежності (якщо ще не встановлені):

```bash
npm install
```

3. Відкрийте Expo Go на телефоні та відскануйте QR-код:

```bash
npx expo start
```

## Опис реалізованого функціоналу
- **Навігація по файловій системі**
  - Відображення поточного шляху у заголовку (`PathBar`).
  - Перегляд вмісту поточної директорії через `FlatList` (папки відображаються першими).
  - Перехід у вкладені папки натисканням на елемент списку.
  - Повернення до батьківської директорії кнопкою «Вгору» (недоступна в кореневій папці).
- **Створення**
  - Створення нової папки з введеною назвою через модальне вікно (`CreateFolderModal`).
  - Створення нового текстового файлу `.txt` з введеним ім'ям і початковим вмістом через модальне вікно (`CreateFileModal`). Розширення `.txt` додається автоматично, якщо не вказано.
- **Зчитування та редагування**
  - Відкриття `.txt` файлів у текстовому редакторі (`TextEditorScreen`).
  - Редагування вмісту файлу через `TextInput`.
  - Збереження змін до файлу з підтвердженням через `Alert`.
- **Видалення**
  - Видалення обраного файлу або папки кнопкою «Видалити».
  - Виведення діалогового вікна підтвердження перед видаленням.
- **Детальна інформація про файл**
  - Виведення атрибутів через `Alert` при натисканні «Деталі»:
    - Назва файлу;
    - Тип (папка або файл із розширенням);
    - Розмір у байтах;
    - Дата останньої модифікації.
- **Статистика пам'яті пристрою**
  - Картка `StorageStats` на головному екрані відображає:
    - Загальний обсяг пам'яті;
    - Обсяг вільного простору;
    - Обсяг зайнятого простору.
  - Значення форматуються автоматично (B / KB / MB / GB).

## Висновки
У ході виконання лабораторної роботи я набула практичних навичок роботи з локальною файловою системою мобільного пристрою засобами бібліотеки `expo-file-system`. Було реалізовано повний набір операцій CRUD над файлами та папками: створення, зчитування, редагування та видалення. Опановано методи отримання метаданих файлів (`getInfoAsync`) та статистики дискового простору (`getTotalDiskCapacityAsync`, `getFreeDiskStorageAsync`). Застосовано компоненти `FlatList`, `TextInput` і модальні вікна для побудови зручного інтерфейсу файлового менеджера.
